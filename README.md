# Emrah Fidan — Portfolio

Personal portfolio website: **https://emrahfidan.netlify.app**

Computer engineer working in business & process development and project management, with a background in software, AI and data.

## What's on the site

- Experience, volunteering, education and publications
- Projects pulled from GitHub at build time, plus shared projects I contributed to
- Downloadable CV

## Built with

- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com)
- GitHub REST API
- [Netlify](https://netlify.com)

## Run locally

```sh
npm install
npm run dev
```

Set a `GITHUB_TOKEN` environment variable to include private and collaborator repositories in the build.
